# 画面デザインと表示仕様

政府調達データ分析ツール / Government Procurement Analytics の表示仕様です。
デジタル庁の公開情報を利用した非公式ツールです。

## 配色とレイアウト

白を基調にネイビーとターコイズを使用します。
取得件数・4種の差分・品質警告を6つのコンパクトなKPIカードに表示します。
表示領域に応じて6列・3列・2列に切り替え、小画面でも数字とラベルを読みやすくします。

|保存された判定|表示|色|
|---|---|---|
|NEW|新規掲載|緑 `#187247`|
|UPDATED|内容更新|紫 `#7541aa`|
|NOT_LISTED|今回の一覧から非掲載|赤 `#b93b4c`|
|UNCHANGED|変更なし|青 `#275eb0`|

案件一覧は全文を折り返すカードと表を切り替えられます。
検索・日付・公告種別の条件は案件一覧だけに適用し、全件のKPI・集計には適用しません。
出典・取得日時・保存ファイル名・サンプルの注記を表示します。

## 判定と表示の対応

差分ラベルは保存済みイベントの`stable_key`でレコードと対応付けます。
画面側で判定を再計算したり、案件名から推測したりしません。
比較結果がない場合は、ゼロ件・変更なしで代用しません。
非掲載案件は比較詳細から参照し、取消・終了・落札を意味しない旨を表示します。
保存された差分要約に更新日がない場合、更新日を推測しません。

表示ヘルパーは保存テキストをHTMLエスケープします。
詳細URLには`safe_detail_url`の検証を適用し、アプリがリンク先の本文を取得することはありません。

公開用の`cloud_app.py`は、2026年10月3日・4日の保存データに固定します。

## 表示確認

Windows／Streamlit 1.65.0でPC・小画面の表示を確認しています。
Linux／Python 3.12.3のオフライン検証でも、1280px幅で6列、390px・320px幅で2列、
ページの横はみ出しなしという結果が報告されています。
StreamlitのDOMや版が変わる場合は、配色・列数・日本語の折返しを再確認してください。
