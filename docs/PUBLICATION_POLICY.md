# 公開対象とローカル保存データ

公開用の入口（`cloud_app.py`）は、Git管理された公開サンプルだけを表示します。
以下は公開用の管理対象と、端末内だけに保持するデータの分類です。

|対象|分類|理由・扱い|
|---|---|---|
|`app.py`、`cloud_app.py`、`src/`|公開用|実装。秘密情報や端末固有の個人パスを含めない|
|`tests/*.py`、`tests/fixtures/`|公開用|オフライン検証。実データ由来fixtureとテスト専用合成データを区別|
|README、requirements、lock、`.streamlit/config.toml`|公開用|再現手順・依存・秘密設定を含まない共通設定|
|`data/samples/`|公開用|検証済み2世代のコピー。出典・PDL1.0・取得日時を保持|
|`docs/`、`docs/screenshots/`|公開用|検証概要と保存データの画面。ユーザー名や秘密情報を含めない|
|本番`data/baselines/`、`data/snapshots/`、`data/diffs/`|除外・ローカル保持|基準・履歴保護。過去のdiff原本には端末の絶対パスがある|
|`logs/`、通信監視ログ|除外・ローカル保持|取得先・保存先・IP・port・PID等のローカル検証情報|
|`work/`、`tests/output/`|除外・ローカル保持|作業控え、一時ランナー、生の検証証跡|
|`.venv/`、Python生成物、キャッシュ|除外|端末固有または再生成可能|
|`.env*`、`.streamlit/secrets.toml`、秘密鍵類|除外|秘密設定|

`.gitignore`と管理対象一覧を照合し、本番保存領域・ログ・仮想環境が混入しないことを確認しています。
新しいdiff JSONのsnapshot参照はファイル名・取得日時・種別を保存し、絶対パスを永続化しません。
既存の本番原本は保護のため書き換えず、既存サンプルの相対参照は読取り互換を維持します。

## データと画像の出典

データ出典：デジタル庁「調達情報」 https://www.digital.go.jp/procurement
公開一覧をGov IT Procurement Watchが取得・加工して作成。デジタル庁公式サービスではありません。
デジタル庁コピーライトポリシーと公共データ利用規約PDL1.0に従います。
外部詳細本文、PDF、担当者情報、認証情報、ロゴ等は公開サンプルに含めません。

`tests/fixtures/phase1a_baseline_copy.json`は検証済み公開一覧のコピーで、SHA-256を固定しています。
`data/samples/`は2026年10月3日／4日の実データコピーです。実比較はNO CHANGEです。
サンプルdiffの2つの参照だけをサンプルフォルダ基準の相対パスへ変更し、案件項目と判定を保持しています。
合成データはテスト中にfixtureから生成し、公開サンプルの実データとは混在させません。
画面画像は保存データを表示したアプリ画面であり、外部サイトのスクリーンショットではありません。

PDL1.0は公開データの利用条件です。プロジェクトのコードに自動適用しません。
このrepositoryの自作コードは[MIT License](../LICENSE)です。
デジタル庁等から取得した公開情報そのものはMITの対象に含めず、提供元の利用条件（公共データ利用規約PDL1.0等）に従います。出典情報は上記のデータと画像の出典に従います。
過去の検証記録でのライセンス未指定という記載は、ライセンス決定前の状態を示します。
